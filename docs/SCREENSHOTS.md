## What the switches control

| Setting | Effect |
| --- | --- |
| Battery percentage | Show/hide the percentage and charging indicator beside the date |
| Show app icons | Show/hide app artwork while retaining app labels |
| Compact app rows | Switch between compact and roomier rows |
| Notification previews | Show/hide available notification snippets on app rows |
| Reduce motion | Disable custom sheet entrance animation; a static image cannot show this difference |
| Black-and-white app icons | Grayscale all app icons, or retain original colors |
| Enable notification access | Open Android’s optional listener permission settings; access is not required to launch apps |
| Hidden apps | Review hidden entries and tap to unhide |
| Refresh apps | Re-query installed launcher activities; no separate result screen |
| Choose default home app | Open Android’s home-app selection settings; Rill never selects itself automatically |
| Choose wallpaper | Open the installed system wallpaper handlers |

All switches are visible in the three settings-panel captures. Notification previews/actions depend on source apps, access and Android version; no private notifications were staged for these screenshots. [Complete behavior and compatibility details](FEATURES.md).
