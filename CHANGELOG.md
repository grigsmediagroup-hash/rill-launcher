# Changelog

## 0.1.0 — personal preview

- Original framework-only list launcher with favorites, search and alphabet navigation.
- Prefix-first search, selected-letter top alignment and finger-following marker.
- Android 6 ListView header/footer layout compatibility fix.
- Home/per-app widget stacks, native second timezone clock and battery percentage.
- Optional local notification previews, actions, dismissal and compatible media controls.
- AMOLED black, transparent wallpaper, dimmed wallpaper and four gradient themes.
- Universal grayscale icon option, text shadows and compact magnifier control.
- Background behind system bars, safe control insets and bottom navigation gradient.

This is a preview release. Android 5 is the declared minimum, not a completed device-certification matrix. See validation notes for test history and remaining gaps.
